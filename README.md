# Virtual Basco

**BASCO — Music Box Reference System** (Frank Basco Project)

Look up TMC music box items, match their tunes to Sankyo movement stock numbers, identify codes stamped on movements, and check stock and eBay listings. It works offline once downloaded (the Listen buttons stream sound samples from BetterMusicBoxes.com and need internet).

## Use it in your browser
**[Open Virtual Basco](https://jedi36.github.io/Virtual-Basco/)** — nothing to install.

## Download for Mac
**[Download BASCO.zip](https://github.com/Jedi36/Virtual-Basco/releases/latest/download/BASCO.zip)**

1. Unzip it and double-click **BASCO.app**.
2. First launch only: macOS will block it because it isn't from the App Store. Open **System Settings → Privacy & Security** and click **Open Anyway**.
3. If the app won't open, double-click **BASCO.html** from the same zip. It's the same program and opens in Safari or Chrome.

## What you can type
- `what do I have in stock`
- `what plays Tea for Two`
- `35-311` (a TMC number)
- `SZ`, `D02`, `K39` or `U03` (a code stamped on a movement)
- `listen to the trout` (hear a 50/72/100-note Orpheus movement)
- `specs` / `suppliers`
- `what isn't on ebay`
- `HELP`

Or click the menu on the left. "Full spreadsheet" shows every tab of the reference workbook, and "Download Excel file" saves it.
